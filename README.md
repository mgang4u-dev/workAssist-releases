# workAssist — 다운로드

**업무 도우미** — 회사 업무 사이트(오피스노트 · Jira)를 조금 더 편하게 쓰는 크롬 확장
(크롬 확장 목록에는 `workAssist`, 팝업 안에서는 **업무 도우미**로 보입니다)

> 처음엔 오피스노트 전용 `noteAssist` 였습니다. Jira 쪽 기능이 늘어 이름을 바꿨습니다.
> **noteAssist 를 쓰고 계셨다면 제거하고 이걸 새로 로드해 주세요.** 설정은 그대로 이어집니다.

- **넓게 보기 기본 활성화** — 새 페이지마다 손으로 켜지 않아도 처음부터 넓게
- **표 여백 축소** — 칼럼이 많은 표를 한 화면에
- **Jira 링크 도우미** — 이슈 번호에 링크 붙이는 손품을 없앰
- **옛 Jira 주소 자동 이동** — 옛 주소로 들어가면 새 주소로

```
● 업무 도우미 v1.1.0
  officenote.ai

  넓게 보기 기본 활성화              [ON]
  표 여백 축소                       [ON]
  Jira 링크 도우미                   [ON]
  Jira 주소 붙여넣기 자동 축약        [ON]

  브라우저 전체
  옛 Jira 주소 자동 이동             [OFF]

  JIRA 기본 주소
  [ https://jiran.atlassian.net/browse/ ]
```

툴바 아이콘을 누르면 이 팝업이 뜹니다. 바꾸는 즉시 저장됩니다.

## 다운로드
최신 릴리스에서 `workAssist-vX.X.X.zip` 을 받으세요 →
**[Releases](https://github.com/mgang4u-dev/workAssist-releases/releases)**

## 설치 방법
1. zip 다운로드 후 **압축 해제**
2. 크롬 주소창에 `chrome://extensions` 입력
3. 우측 상단 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 압축 푼 폴더 선택
5. 오피스노트를 열면 바로 적용됩니다

이미 열려 있던 오피스노트 탭도 새로고침 없이 적용됩니다.

> 새 버전을 올릴 때는 **확장을 먼저 새로고침**하고, 그다음 오피스노트 탭을 새로고침하세요.
> 순서가 반대면 예전 코드가 그대로 물립니다. 팝업 헤더의 버전으로 확인할 수 있습니다.

## 주요 기능

### 넓게 보기 기본 활성화
오피스노트는 넓게 보기를 **페이지마다 따로** 기억합니다. 그래서 새 페이지를 만들 때마다
직접 켜야 했습니다. 이 기능은 아직 정해지지 않은 페이지만 넓게 시작하도록 기본값을 바꿉니다.
**일부러 좁게 해둔 페이지는 그대로 둡니다.**

### 표 여백 축소
셀 안쪽 여백만 줄입니다. 글자 크기는 그대로라 읽기 어려워지지 않습니다.
칼럼 7개짜리 표 기준으로 표 높이가 **386px → 320px** 로 줄어듭니다.

### Jira 링크 도우미
| 하는 것 | 결과 |
|---|---|
| `ABC-1234` 를 드래그 | 작은 단추가 뜹니다. 누르면 링크가 걸립니다 (글자는 그대로) |
| `https://.../browse/ABC-1234` 를 드래그 | `ABC-1234` 로 줄이고 링크를 겁니다 |
| Jira 주소를 **붙여넣기** | 그 자리에서 코드값으로 줄고 링크가 걸립니다 |

어느 쪽이든 **보이는 건 코드값, 걸린 건 전체 주소**입니다.
마우스 대신 단축키 `⌘⇧J`(윈도우 `Ctrl+Shift+J`)로도 됩니다. **붙여넣기가 가장 빠릅니다.**

코드값만 정확히 선택해야 동작합니다 — `100%` `~9/30` `10/8(목)` 같은 표의 흔한 값이나
`ABC-1234 설명`처럼 뒤에 글자가 붙은 경우에는 뜨지 않습니다. 오작동하면 더 귀찮아지니까요.

**Jira 기본 주소**는 팝업 아래 입력칸에서 바꾸세요.

### 옛 Jira 주소 자동 이동
회사 Jira 가 `jd-jira.atlassian.net` 에서 `jiran.atlassian.net` 으로 옮겼습니다.
옛 주소는 새 쪽으로 자동으로 넘겨주지 않아서, 북마크·메신저·문서의 옛 링크가 전부 옛 사이트로 갑니다.

이 기능을 켜면 옛 주소로 들어가는 순간 새 주소로 보냅니다. 경로·쿼리는 그대로 넘어가니
`…/browse/ABC-1234` 는 새 사이트의 같은 티켓으로 갑니다.

**기본은 꺼져 있습니다.** 이전이 끝난 뒤에 켜세요. 브라우저 전체에 걸리는 설정이라
오피스노트 탭이 아니어도 팝업에서 켜고 끌 수 있습니다.

## 개인정보
- 문서 내용을 **어디로도 보내지 않습니다.** 모든 처리는 브라우저 안에서 끝납니다.
- 설정은 오피스노트 페이지의 브라우저 저장소에만 남습니다.
- 접근 권한은 `officenote.ai` · 옛 Jira 도메인(자동 이동용) · `api.github.com`(새 버전 확인용) 입니다.
